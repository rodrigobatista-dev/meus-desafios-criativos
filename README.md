# 💰 Educador Financeiro Inteligente

Projeto de um **Educador Financeiro Inteligente** desenvolvido para ajudar trabalhadores CLT a organizar suas finanças.

## 🎯 Objetivo

Ajudar o usuário a:

* Controlar receitas e despesas;
* Organizar o orçamento mensal;
* Criar metas de economia;
* Acompanhar sua reserva de emergência.

## 🛠️ Tecnologias

* HTML
* CSS
* JavaScript
* React
